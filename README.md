# 27 - 音楽音程暗記ドリル

**ビルド日**: 2026-11-03
**カテゴリ**: fun
**slug**: music-interval-drill

## 概要
長/短/増/減の音程をフラッシュカードで暗記し、4択クイズで学習するドリル。Web Audio APIで実際の音程を再生しながら耳でも確認できる。

## 機能
- 13種類の音程データ（完全1度〜完全8度）
- フラッシュカードモード：音程名→半音数・別名・例音を表示
- 4択クイズ（半音数→音程名）
- 逆4択クイズ（音程名→半音数）
- Web Audio APIで2音の音程を再生
- 正解/不正解の統計と正答率をlocalStorageに保存
